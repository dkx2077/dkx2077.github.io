# 3D 场景维护

桌面默认入口是固定机位的雨夜赛博朋克街区；触屏设备默认进入原生滚动的阅读页，可通过 Explore 3D 进入街区，已保存的模式选择优先。Three.js 渲染建筑、街道、灯管、雨和远景；CSS3DRenderer 把真正的 HTML 文字变换到同一空间。姓名、招牌和链接不在背景图片里，不需要重新生成图片即可修改。

## 控制

- 电脑：按下并拖动环视；先聚焦场景后用方向键旋转，Shift 加速，Home 复位。
- 手机和平板：单指拖动；点击招牌或顶部栏目查看内容；底部按钮转向对应街区。
- 水平连续旋转；垂直默认为向下 28°、向上 48°。不移动相机、不缩放、不锁定鼠标，也不读取陀螺仪。
- 招牌链接是真正的锚点。拖动超过阈值后抑制误点；Ctrl/Command 点击和中键保留浏览器行为。
- 阅读面板支持键盘焦点循环、Escape 关闭、恢复原焦点、链接深链和浏览器返回。打开时暂停 GPU 动画。
- Reading mode 切换为完整可滚动正文；可返回 3D。浏览器打印始终输出完整正文。

## 兼容与性能策略

| 情况                                              | 行为                                                                       |
| ------------------------------------------------- | -------------------------------------------------------------------------- |
| 桌面 Auto                                         | DPR 上限 1.5、泛光、单张静态阴影；持续帧耗时过高时降到低画质               |
| 触屏 / 节省流量 / 低内存设备 Auto                 | DPR 上限 1，取消泛光和阴影，减少雨滴，空闲动画约 30 fps                    |
| 手动画质                                          | 可选 Auto / Low / High，保存为当前浏览器偏好                               |
| 减少动态效果                                      | 默认直接进入阅读模式，不下载 3D 模块；主动进入后关闭环境动画，视角即时响应 |
| 页面隐藏、阅读模式、打开正文面板                  | 暂停渲染，重新进入时恢复                                                   |
| WebGL2 不可用、场景模块加载失败、WebGL 上下文丢失 | 展示完整正文，不阻塞论文或邮箱链接                                         |
| 禁用 JavaScript、模块脚本不支持                   | 直接阅读已生成 HTML，无需运行时解析 Markdown                               |
| 移动端捏合放大                                    | 自动进入阅读模式，保留文字放大能力                                         |
| 本地存储被拒绝                                    | 继续正常使用，偏好仅在当前运行期间生效                                     |

Three.js r185 使用 WebGL2。CSS3DRenderer 官方支持范围是 100% 浏览器/显示缩放，因此高倍率桌面缩放或个别合成器上的 3D 标签对齐不保证完全一致；阅读模式提供普通 HTML 布局。不能把桌面构建或 DOM 测试等同于真实 iPhone/Android/GPU 验收。正式替换前建议在实际 Safari、Chrome、Firefox 检查 320/390/768/1440px、横竖屏与 200% 文字缩放。

高画质在启用时生成单张静态方向光阴影，不逐帧更新；局部水滩共享一个 512px 平面反射目标，可见时最多约 20 次/秒捕获建筑与灯管。Low 不进行这次额外捕获，保留程序化水光。粗糙地面与小水滩分层，远景是贴图，近景是实际几何体。建筑、窗户和近景的重复金属构件按材质实例化；站内打包固定版本的 Three.js，访客不依赖第三方代码 CDN。招牌置于面向固定观察点的建筑前方，通过视锥和朝向过滤隐藏屏幕外与背面的链接，并移出键盘焦点序列；这不是可漫游场景，也没有为自由移动实现通用 DOM/WebGL 遮挡系统。

自动检查覆盖：连续水平转向、上下边界、触屏拖动与点击区分、键盘复位、面板焦点与退出、阅读模式、弱能力降级、所有原有 Umami 事件规则。已在实际云端 Chrome 检查 WebGL 失败降级与多种阅读视口；该环境禁用 WebGL，尚未验证 3D 画面、实机帧率或实际 Umami 入库。详见 [浏览器检查记录](QA-2026-09-05.md)。

实现参考：[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[CSS3DRenderer](https://threejs.org/docs/pages/CSS3DRenderer.html)。

## 霓虹街区美术更新

大学竖牌已移除，包括文字、实体底板和专属样式。栏目招牌使用本地 Rajdhani 600 拉丁字符字体，统一编号、灯管文字和底部说明的层级，保留真实 HTML 与链接。非拉丁文字仍使用系统字体。

`design.mjs` 同时定义 DOM 文字面的像素尺寸与 Three.js 底板的世界尺寸，避免以前面板与实体边缘不一致。实体层包含金属底板、搪瓷面、发光导轨和安装支架；字体本身用 CSS text-shadow 发光，因为 CSS3D 不参与 WebGL 泛光或阴影。

青蓝、紫红、琥珀色灯光由同一组配置驱动点光源和地面径向反光。铺装以程序化噪声、抗锯齿砖缝与断续水光表现湿润粗糙度，背景使用城市全景；地面叠加标准 ShadowMaterial 接收高画质静态阴影。最新水滩层另见下文。Auto 降档和手动 Low 均同步减少雨滴绘制与 CPU 更新，暂停模式在远景加载完成后也会补渲染一帧。

窄长手机按宽高比扩大纵向视场，保持至少约 42° 的水平视野（纵向上限 105°）；相机位置与用户俯仰边界不变。

## 建筑照明更新

场景顶部的两组装饰文字已移除。背景建筑采用深蓝灰墙面与 0.32 金属度，保留局部彩光的漫反射；管线和框架保留较高金属度，体现环境高光。曝光设为 1.0，主灯只帮助辨识形体，视觉重点留给霓虹。

- 专用反射环境：以四条窄彩色光带和一块暗蓝顶面生成一次 128px PMREM，供金属材质使用，无 HDR 文件下载、无逐帧反射捕捉。
- 立体照明：朝南／西立面的高位冷色主灯、反方向柔光、28–34m 范围的街区点灯，以及两盏朝向高层的青色／洋红泛光灯。
- 高画质：一盏主灯生成 2048px PCF 阴影，缓存后不随环视重绘；只让实体 PBR 建筑和招牌投影，窗片与霓虹不参与阴影绘制。
- 低画质：关闭阴影层、阴影采样和泛光，保留环境反射与局部照明。回到 High 时重新请求一次阴影。
- 销毁时显式释放 PMREM 目标和阴影目标，其他几何／材质继续统一去重释放。

CSS3D 招牌文字不参与 WebGL 阴影；保留原有文字表现。光影的 CPU 配置与覆盖检查不能替代 GPU 画面验收。

## 霓虹夜景美术方向

建筑以深蓝黑暗部为底，局部青色／洋红受光勾勒立面，少量琥珀用于 Awards 招牌和零星窗灯。避免把每面墙均匀照亮，保留塔楼、连桥和招牌之间的明暗层级。

- 主光／反向柔光／半球光分别收至 0.9／0.38／0.24；保留现有静态阴影。
- 反射环境由大面积浅色软箱改为窄幅饱和彩条，强度从 0.65 收至 0.28，移除明亮的白色顶面。
- 高层泛光锥收至 40.5°，点灯缩短范围，减少不同颜色覆盖同一大片墙面造成的泛白。
- 灯管采用更纯的青、洋红、橙，降低发光倍率；紧凑泛光阈值改为 0.42、半径 0.3、强度 0.46，使较低亮度的彩色灯管也能形成光晕。
- 文字继续使用真实 HTML；栏目白色通用光晕改为各自霓虹颜色，姓名保留一行淡冰蓝与一行青绿。导航强调色同步改为青绿。
- 窗灯、雨与地面反光同步收敛；反射更窄、更断续，避免整片地面与招牌争夺亮度。

这轮只改变材质、灯光、颜色与泛光参数，没有增加建筑、光源、下载资源或渲染通道。

## 远景与几何风格统一

远景替换为 `night-district-v3.webp`：简洁、低对比的深靛蓝城市轮廓，只保留零星青色与洋红窗灯。弱化照片式细节与大面积亮雾，使其与前景几何楼体协调。图片 2172 × 724，约 36.5 KiB；旧贴图不再进入部署产物。

背景圆柱半径 110m、高度约 76.8m，中心降至 30m；三次重复与素材 3:1 比例匹配，避免塔楼被竖向拉长。使用标准 MeshBasicMaterial、sRGB 贴图与 0.82 整体透明度，保持现有 ACES 流程。RGBA 顶点透明度在上下边缘和重复接缝处淡出；深度测试保留、深度写入关闭，背景由真实楼体遮挡。圆柱仍为单次绘制，4,608 个三角形，高低画质共用，无额外光源或后处理。

加载成功前不显示圆柱，失败时保留程序化建筑；异步加载后的补帧与销毁逻辑保持有效。

## 移动阅读与触控

- 触屏初次访问不初始化 3D 模块，默认使用普通 HTML 阅读页；手动进入或已有 city 偏好时才初始化场景。桌面、减少动态与 WebGL 失败降级继续保留。
- 触屏设备及宽度不超过 760px 的阅读面板使用文档本身滚动，不采用固定面板内的第二个滚动容器；触屏横竖屏均保持这一策略。桌面保留侧边面板。返回城市按钮粘附在面板顶部。
- 只在城市模式锁定页面；阅读模式支持单指纵向滚动、系统惯性与双指缩放。3D 中允许原生双指缩放，放大后转入阅读。场景暂停时不再响应拖动或方向键。
- 触屏水平拖动按视口宽度调整灵敏度，一屏手势约转动 90°，垂直灵敏度更低且仍有上下界；修复拖动指针外观。相机位置不变。
- 从阅读切换到城市再返回时恢复原阅读位置；恢复和面板定位使用即时滚动，焦点恢复不再强制跳到页首。主动进入 3D 时不会被阅读页的旧栏目锚点立即拉回正文。
- 阅读导航保持可见，实际栏高用于锚点避让；文字放大后允许导航换行。正文使用系统字体、16px 基础字号；论文标题、作者、刊会标签与 44px 高的链接按钮分层，移除表情式箭头和竖线分隔。
- `contents/publications.md` 中每个 publication 标识后按“刊会标签、三级标题、作者（如有）、链接和归属”排列；论文 ID、原题、作者、链接与统计分类保持不变。
- 阅读首屏复用已存在的轻量城市远景，不增加图片或运行时依赖；打印隐藏交互控件、取消卡片深色背景。

`tests/browser-qa.html` 提供本地视口、200% 根字号及正文面板布局检查。面板布局按钮只设置 HTML/CSS 状态，不创建虚假 3D 渲染器，不进入生产产物；不能据此宣称完成 GPU 或实体设备验收。

## Google Scholar 与雨夜水滩

东南侧原小号 `KAIXIN DENG / RESEARCH DISTRICT` 装饰牌改为 Google Scholar，首页大姓名牌不变。标题、说明与地址在 `contents/scene.yml` 的 `scholar-*` 三项维护；链接为原有个人页面 `WsJD-ukAAAAJ`，保留原生新标签页、键盘操作与 `profile_click / google_scholar` 统计。真实 HTML 字体与同色实体灯轨配合，不生成文字图片。

水滩为分散的不规则浅水面，铺装大部分仍然可见。High 使用 Three.js r185 自带 Reflector，共享一次场景捕获，水面 shader 加入边缘渐隐、Fresnel 掠射增强、五点柔化、局部扩散雨环、波纹法线扰动与克制的霓虹高光。Low 保留相同水滩轮廓和轻量波纹，用现有街区灯色计算水光，不捕获场景。

高画质雨量从 650 增至 1,800 条、低画质从 240 增至 560 条，雨线长度与速度有差异，亮头淡尾接收附近青色、洋红及琥珀色。仍只使用一个 LineSegments draw call，Low 仅更新激活的雨滴，暂停或减少动态模式冻结水纹并隐藏雨线；页面隐藏和阅读面板继续暂停整场渲染。

完整选型依据、成本与已知限制见 [雨水与反射实现](RAIN-REFLECTIONS.md)。CSS3D 文字不在 WebGL 捕获中，因此倒影包含建筑、窗格、招牌实体底板和灯轨，不包含 HTML 字形。不要把这些小水滩描述为完整光线追踪、流体模拟或包含所有文字的镜面。
