# 3D 场景维护

页面入口是固定机位的雨夜赛博朋克街区。Three.js 渲染建筑、街道、灯管、雨和远景；CSS3DRenderer 把真正的 HTML 文字变换到同一空间。姓名、招牌和链接不在背景图片里，不需要重新生成图片即可修改。

## 内容与招牌

| 要修改的内容                                   | 源文件                                       |
| ---------------------------------------------- | -------------------------------------------- |
| 姓名、招牌标题、欢迎语、默认画质、俯仰范围     | `contents/scene.yml`                         |
| 简介、教育、经历、Google Scholar、GitHub、邮箱 | `contents/home.md`                           |
| 论文标题、作者、论文/项目/代码链接             | `contents/publications.md`                   |
| 奖项、现有工作                                 | `contents/awards.md`、`contents/service.md`  |
| 正式域名、停更说明、统计 ID、版权说明          | `contents/config.yml`                        |
| 招牌 HTML、精选论文入口                        | `templates/index.html` 的 `world-signs` 模板 |
| 招牌位置、尺寸、配色、灯光位置                 | `static/js/scene/design.mjs`                 |
| 招牌实体底板、灯管与支架                       | `static/js/scene/signs.mjs`                  |
| 建筑、灯管、材质、雨与远景                     | `static/js/scene/environment.mjs`            |
| 环境反射、主光、泛光灯与静态阴影               | `static/js/scene/lighting.mjs`               |

修改后运行 `npm run build`。正文只有一份，由构建器生成完整 HTML；阅读模式、3D 阅读面板和无 JavaScript 页面共享这份内容。保留 publication 标识，避免历史统计被拆分。当前精选入口指向 `supergpqa`，删除这篇论文时也要修改对应招牌链接。

原有“2026 年 1 月起不再更新”的说明仍保留；本次视觉改造没有推断或更新个人教育、工作经历。原有工作内容只有省略号，因此页面明确显示尚未列出工作，不补写虚构项目。

## 控制

- 电脑：按下并拖动环视；先聚焦场景后用方向键旋转，Shift 加速，Home 复位。
- 手机和平板：单指拖动；点击招牌或顶部栏目查看内容；底部按钮转向对应街区。
- 水平连续旋转；垂直默认为向下 28°、向上 48°。不移动相机、不缩放、不锁定鼠标，也不读取陀螺仪。
- 招牌链接是真正的锚点。拖动超过阈值后抑制误点；Ctrl/Command 点击和中键保留浏览器行为。
- 阅读面板支持键盘焦点循环、Escape 关闭、恢复原焦点、链接深链和浏览器返回。打开时暂停 GPU 动画。
- Reading mode 切换为完整可滚动正文；可返回 3D。浏览器打印始终输出完整正文。

## 兼容与性能策略

| 情况                                              | 行为                                                                       |
| ------------------------------------------------- | -------------------------------------------------------------------------- |
| 桌面 Auto                                         | DPR 上限 1.5、泛光、单张静态阴影；持续帧耗时过高时降到低画质               |
| 触屏 / 节省流量 / 低内存设备 Auto                 | DPR 上限 1，取消泛光和阴影，减少雨滴，空闲动画约 30 fps                    |
| 手动画质                                          | 可选 Auto / Low / High，保存为当前浏览器偏好                               |
| 减少动态效果                                      | 默认直接进入阅读模式，不下载 3D 模块；主动进入后关闭环境动画，视角即时响应 |
| 页面隐藏、阅读模式、打开正文面板                  | 暂停渲染，重新进入时恢复                                                   |
| WebGL2 不可用、场景模块加载失败、WebGL 上下文丢失 | 展示完整正文，不阻塞论文或邮箱链接                                         |
| 禁用 JavaScript、模块脚本不支持                   | 直接阅读已生成 HTML，无需运行时解析 Markdown                               |
| 移动端捏合放大                                    | 自动进入阅读模式，保留文字放大能力                                         |
| 本地存储被拒绝                                    | 继续正常使用，偏好仅在当前运行期间生效                                     |

Three.js r185 使用 WebGL2。CSS3DRenderer 官方支持范围是 100% 浏览器/显示缩放，因此高倍率桌面缩放或个别合成器上的 3D 标签对齐不保证完全一致；阅读模式提供普通 HTML 布局。不能把桌面构建或 DOM 测试等同于真实 iPhone/Android/GPU 验收。正式替换前建议在实际 Safari、Chrome、Firefox 检查 320/390/768/1440px、横竖屏与 200% 文字缩放。

高画质在启用时生成单张静态方向光阴影，不逐帧更新；场景不使用平面反射的额外相机。地面是程序化霓虹反光材质，远景是贴图，近景是实际几何体。建筑、窗户和近景的重复金属构件按材质实例化；站内打包固定版本的 Three.js，访客不依赖第三方代码 CDN。招牌置于面向固定观察点的建筑前方，通过视锥和朝向过滤隐藏屏幕外与背面的链接，并移出键盘焦点序列；这不是可漫游场景，也没有为自由移动实现通用 DOM/WebGL 遮挡系统。

自动检查覆盖：连续水平转向、上下边界、触屏拖动与点击区分、键盘复位、面板焦点与退出、阅读模式、弱能力降级、所有原有 Umami 事件规则。已在实际云端 Chrome 检查 WebGL 失败降级与多种阅读视口；该环境禁用 WebGL，尚未验证 3D 画面、实机帧率或实际 Umami 入库。详见 [浏览器检查记录](QA-2026-09-05.md)。

实现参考：[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[CSS3DRenderer](https://threejs.org/docs/pages/CSS3DRenderer.html)。

## 霓虹街区美术更新

大学竖牌已移除，包括文字、实体底板和专属样式。栏目招牌使用本地 Rajdhani 600 拉丁字符字体，统一编号、灯管文字和底部说明的层级，保留真实 HTML 与链接。非拉丁文字仍使用系统字体。

`design.mjs` 同时定义 DOM 文字面的像素尺寸与 Three.js 底板的世界尺寸，避免以前面板与实体边缘不一致。实体层包含金属底板、搪瓷面、发光导轨和安装支架；字体本身用 CSS text-shadow 发光，因为 CSS3D 不参与 WebGL 泛光或阴影。

青蓝、紫红、琥珀色灯光由同一组配置驱动点光源和地面径向反光。地面以噪声水洼遮罩、抗锯齿砖缝与断续涟漪控制反射，背景使用新一版城市全景；地面上叠加标准 ShadowMaterial 接收高画质静态阴影，不逐帧重拍场景生成反射。Auto 降档和手动 Low 均同步减少雨滴绘制与 CPU 更新，暂停模式在远景加载完成后也会补渲染一帧。

窄长手机按宽高比扩大纵向视场，保持至少约 42° 的水平视野（纵向上限 105°）；相机位置与用户俯仰边界不变。

## Awards 与 Ongoing 街区补充

南侧 Awards 和西侧 Ongoing 各补四栋错落塔楼、带窗空中连桥、设备平台和霓虹构件，西南转角增加 24 米高的楼体以连接两个街区。所有新建筑位于现有招牌后方；远景继续复用城市全景，不增加图片下载。

远楼原先统一设置 +Z / −X 两面窗，造成南、西方向的窗户朝外。本轮改为选择朝向固定观察点的两面，侧窗按建筑深度排列，避免宽浅楼窗户越界。新增近中景的窗、设备和框架继续按材质实例化；不增加点光源、实时阴影或后处理通道。

## 建筑照明更新

场景顶部的两组装饰文字已移除。背景建筑主墙基色提高，金属度从 0.68 降至 0.32，使材质能接收足够漫反射；管线和框架保留较高金属度，体现环境高光。曝光维持 1.08，减少边缘暗角，避免同时把栏目文字推亮。

- 专用反射环境：以五块彩色光面生成一次 128px PMREM，供金属材质使用，无 HDR 文件下载、无逐帧反射捕捉。
- 立体照明：朝南／西立面的高位冷色主灯、反方向柔光、48m 范围的街区点灯，以及两盏朝向高层的琥珀／紫红泛光灯。
- 高画质：一盏主灯生成 2048px PCF 阴影，缓存后不随环视重绘；只让实体 PBR 建筑和招牌投影，窗片与霓虹不参与阴影绘制。
- 低画质：关闭阴影层、阴影采样和泛光，保留环境反射与局部照明。回到 High 时重新请求一次阴影。
- 销毁时显式释放 PMREM 目标和阴影目标，其他几何／材质继续统一去重释放。

CSS3D 招牌文字不参与 WebGL 阴影；保留原有文字表现。光影的 CPU 配置与覆盖检查不能替代 GPU 画面验收。
