`npm test` 验证 14 项检查，包括固定机位水平角跨界、俯仰限制、触摸 PointerEvent 拖动误点抑制、键盘复位、阅读面板焦点与 Escape、无 WebGL/模块加载失败/拒绝存储的降级，以及原有 Umami 的事件和隐私边界。这里的触摸检查是事件模拟，不是实体手机操作。

## 可复现的本地预览

```bash
npm ci
npm run build
npm run dev
```

Vite 仅服务 `dist/` 的生产构建；`/__qa` 提供视口测试界面。测试界面由开发中间件提供，不进入 GitHub Pages 部署产物。源码改动后重新构建即可检查新版本。

尚待后续在支持 WebGL2 的实体设备上核验：霓虹与建筑对齐、360° 环视、上下限制、招牌点击、阅读模式返回、实际触控和持续帧率；桌面 200% 缩放与不同浏览器也仍需单独验收。
