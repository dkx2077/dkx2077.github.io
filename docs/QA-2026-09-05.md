## 霓虹美术第二版复核

本轮继续保留上述实机测试边界，没有将 CPU 几何检查当作 GPU 画面验收。自动回归增加至 17 项，已验证：

- DOM 招牌宽高与真实 Three.js 搪瓷底板对应；字面位于底板前方。
- 转向时屏幕外链接同步隐藏并退出键盘导航，回到对应街区后恢复。
- 高／低画质切换同时改变雨滴 drawRange 和 CPU 更新范围，暂停时不更新雨滴。
- 近景重复构件保留实例化，场景基础绘制次数低于 25（不含招牌、后处理）。
- 初始姓名招牌在 320×844、360×915、390×844、768×1024、844×390、1440×900 的水平投影均完整；窄长屏视场角根据宽高比自适应。

独立只读复核使用真实场景几何，在各招牌上取 9 点进行 CPU 射线检查，未发现现有建筑遮挡；字体度量确认当前英文标题能放入面板。保留 ACES / sRGB 输出流程。静态检查未发现地面 shader 语法问题，但尚未在可用 GPU 上编译或观测实际画面。

额外修复了实例对象销毁时的专属 GPU 缓冲释放，以及减少动态模式中远景加载完成后未补渲染的问题。
